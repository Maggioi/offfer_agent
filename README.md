A program to automate making offers at my work.
Jak używać:
0. Przed pierwszym użyciem ustawić na pierwszej stronie kto przygotował ofertę (Offer prepared by: ...)
1. Do folderu z plikiem main.exe wrzucić kalkulator
2. Odpalić program main.exe
3. Program na podstawie kalkulatora przygotuje i odpali nam ofertę w Wordzie.
